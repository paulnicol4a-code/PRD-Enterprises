# PRD-Enterprises

Central repository for PRD-Enterprises projects, documents, templates, spreadsheets, PDFs, research, and supporting data.

## Repository principles

- Keep important project files in one central location.
- Preserve version history rather than overwriting important work without a record.
- Keep reusable templates in `Templates/`.
- Keep project-specific working files inside `Projects/`.
- Record significant changes in `CHANGELOG.md`.
- Keep `PROJECT_INDEX.md` current as projects are added or substantially changed.

## Current projects

- Receipts
- Piercing Businesses
- State Itineraries

## File conventions

Use clear names with dates or version numbers where useful, for example:

`Piercing_Businesses_Master_v001.xlsx`

`Receipts_Master_2026-09-18.xlsx`
